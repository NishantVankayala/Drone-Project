Project Lahaina – Source Codes

This repository contains the source code developed for Project Lahaina, a drone-based fire and smoke detection project.

Technologies Used
- Python
- OpenCV
- YOLO
- TensorFlow
- DJI SDK

Development & Authorship
I independently developed the project's pseudocode, software workflow and initial implementation, with some guidance from my mentor. I 
subsequently used AI-assisted coding tools to complete and adapt portions of the code to meet the project's objectives.
The project-specific logic, intended functionality and development direction were my own.

Third-Party Tools
Python, OpenCV, TensorFlow, YOLO and the DJI SDK are existing technologies used in this project. They are not my original creations. Their 
respective documentation and resources are acknowledged.
